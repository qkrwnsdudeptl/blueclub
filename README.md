# erp비스무리

업무용 PC 한 대에서 실행하는 내부망용 재고·거래 관리 웹앱입니다. 브라우저에서 사업단을 선택하고, 각 사업단의 거래·재고·생산을 별도 SQLite 파일로 관리합니다.

## 주요 기능

- **거래 및 재고** · 매입, 매출, 불출, 반품을 기록하고 기간·품목·거래처로 조회합니다. 재고 조정은 증가, 감소, 수량 변경을 지원합니다. 수량 변경은 목표 재고와 저장 시점의 재고 차이만 장부에 기록합니다.
- **품목 관리** · 재고품과 용역·서비스를 구분합니다. 사용 중인 재고품만 담은 재고조사표를 등록순 또는 가나다순으로 정렬해 Word에서 편집 가능한 RTF로 저장할 수 있습니다.
- **보고서** · 일일 운영일지의 품목별 요약과 거래별 나열, 월간 거래요약, 달력 대장을 제공합니다. 일일·월간 보고서에서 출력 항목을 선택해 인쇄하거나 PDF로 저장할 수 있습니다.
- **엑셀 가져오기** · 지원하는 운영일지와 재고조사 양식을 읽어 반영합니다. 재고 수량만 있는 자료는 조사 기록으로 저장합니다.
- **생산** · 완성품별 재료와 포장 환산을 설정합니다. 생산을 기록하면 한 건으로 완성품을 입고하고 재료를 차감합니다. 공동작업장 라온에 기본 적용되며, 관리자에서 사업단별로 켤 수 있습니다.
- **관리자** · 사업단과 테마, 홈 화면 항목, 환영 화면, 공지를 관리합니다. 사업단별 백업·복원과 데이터 초기화를 지원합니다.

## Windows에서 실행

Python 3.10 이상을 설치하고 `python`을 PATH에 추가합니다. 서버는 Python 표준 라이브러리로 실행됩니다.

처음 확인할 때는 프로젝트 폴더에서 PowerShell을 열고 다음을 실행합니다.

```powershell
$env:ERP_HOST = '127.0.0.1'
python app.py
```

브라우저에서 [로컬 서버](http://127.0.0.1:8000)를 엽니다. 기본 운영 주소는 `192.168.100.117:8000`입니다. 다른 PC를 서버로 쓰려면 `ERP_HOST`에 해당 PC의 내부망 IPv4 주소를 지정합니다. 포트는 `ERP_PORT`로 바꿀 수 있습니다. 접속할 PC가 있는 내부망에만 해당 TCP 포트의 인바운드를 허용합니다.

관리자 기능을 사용하려면 프로젝트 루트의 `admin.local`에 관리자 코드를 한 줄로 설정하거나, 서버를 시작하기 전에 `ERP_ADMIN_CODE` 환경 변수를 지정합니다. 환경 변수가 우선합니다.

### Windows 실행기

`start_inventory.bat`는 같은 폴더에 `InventoryServer.exe`가 있으면 실행기를 열고, 없으면 Python 서버를 실행합니다. 실행기는 트레이와 Windows 로그인 시 자동 시작을 지원합니다. 실행기 소스는 `launcher/ServerWindow.cs`에 있으며, .NET Framework C# 컴파일러가 있는 Windows에서 다음과 같이 빌드할 수 있습니다.

```powershell
$csc = Join-Path $env:WINDIR 'Microsoft.NET\Framework64\v4.0.30319\csc.exe'
& $csc /nologo /target:winexe /codepage:65001 /out:InventoryServer.exe /reference:System.Windows.Forms.dll,System.Drawing.dll,System.Web.Extensions.dll launcher\ServerWindow.cs
```

## 데이터와 백업

실행하면 내일배송의 데이터는 `inventory.db`, 다른 사업단의 데이터는 `business_data/`에 저장됩니다. `backups/`에는 사업단별 일일 백업과 엑셀 반영, 복원 및 초기화 전 백업이 생성됩니다. 관리자 메뉴에서 사업단별 데이터를 SQLite 또는 JSON으로 내보내거나 복원할 수 있습니다.

운영 DB, 백업, 공지, 사업단 설정, 로컬 관리자 코드, 로그와 빌드된 실행기는 Git에서 제외합니다. 기존 서버를 옮길 때는 소스와 운영 데이터를 별도로 이전합니다.

## 소스 구성

| 경로 | 역할 |
| --- | --- |
| `app.py` | HTTP 서버, 거래 및 재고, 보고서, 관리자 API |
| `production.py` | 생산 구성, 재료 및 포장 환산, 생산 기록 |
| `static/` | 웹 화면, 스타일, Pretendard 폰트와 라이선스 |
| `launcher/ServerWindow.cs` | Windows 트레이 실행기 |

품목별 실사 주기, 작업일지 기반 생산능력 통계, 카페 레시피 차감, 발주 후보는 다음 단계의 설계 항목입니다.
